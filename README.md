# 🛍️ Retail Sales Analysis using SQL

## 📌 Project Overview

This project analyzes a retail sales dataset containing **1,987 transactions** using **MySQL**. The objective is to answer real-world business questions, perform data cleaning, and generate meaningful insights through SQL queries.

---

## 📂 Dataset

* **Dataset:** Retail Sales Dataset
* **Total Records:** 1,987
* **Database:** MySQL
* **Table:** `retail_sales_clean`

## 📊 Business Questions Solved

1. Retrieve sales made on **2022-11-05**
2. Find Clothing sales with quantity greater than 4 in November 2022
3. Calculate total sales by category
4. Find the average age of Beauty category customers
5. Retrieve transactions with total sales greater than 1000
6. Count transactions by gender and category
7. Calculate average monthly sales
8. Find the top 5 customers by total sales
9. Count unique customers in each category
10. Categorize sales into Morning, Afternoon, and Evening shifts
