# 🛍️ Retail Sales Analysis using SQL

## 📌 Project Overview

This project analyzes retail sales data using SQL to answer business questions and generate meaningful insights. The analysis focuses on customer behavior, product performance, revenue trends, and sales performance.

---

## 🎯 Objectives

- Analyze retail sales data
- Identify top-selling products
- Calculate monthly revenue trends
- Analyze customer purchasing behavior
- Generate business insights using SQL
